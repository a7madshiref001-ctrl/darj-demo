# DARJ — café POS (Demo)

نسخة عرض لنظام كاشير للكافيهات في السعودية: البيع والإضافات والدفع المقسّم (كاش · مدى · Apple Pay · STC Pay)، شاشة الباريستا، شاشة «طلبك جاهز» وشاشة العميل، الوردية بالقفل الأعمى وتقرير Z، المخزون بالجرام والوصفات والجرد والهالك، العملاء والولاء، التقارير، الصلاحيات وسجل الحركات، والفاتورة الضريبية المبسطة بـQR (المرحلة الأولى).

- الكافيه («هَيل») والأسماء والأرقام كلها وهمية. الرقم الضريبي رقم تجريبي.
- مفيش backend: البيانات بتتولّد في المتصفح وبتتحفظ في localStorage، والتابات بتتزامن مع بعض.
- PIN التجربة: ريم 1111 · فيصل 2222 · Joseph 3333 · سارة 4444 · نورة 9999.
- الصفحات `noindex`.
